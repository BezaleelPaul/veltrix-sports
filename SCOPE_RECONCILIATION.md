# REVISED MVP SCOPE

## What's Actually in the 2-Week MVP

### Training Plans
- User registration & authentication
- Coach and athlete dashboards (basic)
- Training plan catalog (Running, Triathlon, Biking, Nutrition, Hydration, S&C)
- Plan purchase via Razorpay
- Basic progress tracking
- Basic analytics

### Events
- Event listing and discovery
- Event registration
- Ticket purchase via Razorpay
- Basic event details

### Ticketing
- Basic ticket marketplace
- QR code check-in
- Event reviews (basic)

### Infrastructure
- User database
- Server, hosting, domain
- API integration
- Basic analytics
