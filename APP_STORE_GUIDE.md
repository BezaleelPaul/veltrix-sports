# VELTRIX SPORTS
## Google Play & Apple App Store Publishing Guide

---

# 1. GOOGLE PLAY STORE

## 1.1 Prerequisites

| Item | Requirement |
|------|-------------|
| Google Account | Gmail account |
| Developer Fee | ₹18,000 (One-time) |
| Bank Account | For payments |
| GST Number | For Indian developers |

## 1.2 Step-by-Step Process

### Step 1: Create Developer Account
1. Go to https://play.google.com/console
2. Sign in with Gmail
3. Click "Create Developer Account"
4. Pay ₹18,000 (one-time fee)
5. Fill developer details:
   - Developer name: "Veltrix Sports"
   - Email: your@email.com
   - Phone: +91XXXXXXXXXX
6. Verify email
7. Account created in 24-48 hours

### Step 2: Create App
1. Go to Google Play Console
2. Click "Create App"
3. Fill details:
   - App name: "Veltrix Sports"
   - Default language: English
   - App or game: App
   - Free or paid: Free
4. Accept declarations
5. Click "Create App"

### Step 3: Complete Store Listing
1. Go to "Store presence" → "Main store listing"
2. Fill:
   - App name (max 30 chars)
   - Short description (max 80 chars)
   - Full description (max 4000 chars)
3. Upload:
   - App icon (512x512 PNG)
   - Feature graphic (1024x500 PNG)
   - Screenshots (min 2, max 8)
     - Phone: 16:9 or 9:16 ratio
     - Tablet: 16:10 or 10:16 ratio

### Step 4: Content Rating
1. Go to "Store presence" → "Content rating"
2. Fill questionnaire
3. Get rating (Everyone, Teen, Mature)
4. Submit for rating

### Step 5: Pricing & Distribution
1. Go to "Store presence" → "Pricing & distribution"
2. Set price: Free
3. Select countries
4. Accept terms

### Step 6: App Content
1. Go to "App content"
2. Complete:
   - Privacy policy URL
   - App access
   - Ads declaration
   - Content rating
   - Data safety

### Step 7: Upload APK/AAB
1. Go to "Production" → "Create new release"
2. Upload AAB file (recommended)
3. Add release notes
4. Review and start rollout

### Step 8: Review
1. Submit for review
2. Review takes 1-7 days
3. Fix any issues
4. App goes live

# 2. APPLE APP STORE

## 2.1 Prerequisites

| Item | Requirement |
|------|-------------|
| Apple ID | Apple account |
| Developer Fee | ₹7,500/year |
| Mac Computer | For Xcode |
| Bank Account | For payments |
| GST Number | For Indian developers |

## 2.2 Step-by-Step Process

### Step 1: Create Developer Account
1. Go to https://developer.apple.com
2. Sign in with Apple ID
3. Click "Join the Apple Developer Program"
4. Pay ₹7,500/year
5. Fill legal entity details:
   - Organization: "Veltrix Sports"
   - D-U-N-S Number: (Get from Apple)
   - Website: veltrixsports.com
6. Verify organization
7. Account approved in 24-48 hours

### Step 2: Get D-U-N-S Number
1. Go to https://developer.apple.com/enroll/duns-lookup/
2. Search your company
3. If not found, request new D-U-N-S number
4. Wait 7-14 business days
5. Free service from Apple

### Step 3: Create App ID
1. Go to Apple Developer → Certificates, Identifiers & Profiles
2. Click "+" to create App ID
3. Select "App IDs"
4. Fill:
   - Description: "Veltrix Sports"
   - Bundle ID: "com.veltrix.sports"
5. Enable capabilities:
   - Push Notifications
   - Sign in with Apple
6. Register

### Step 4: Create Provisioning Profile
1. Go to "Profiles"
2. Click "+" to create profile
3. Select "App Store"
4. Select App ID
5. Select certificate
6. Name: "Veltrix Sports App Store"
7. Download profile

### Step 5: Create Certificate
1. Go to "Certificates"
2. Click "+" to create certificate
3. Select "iOS Distribution"
4. Upload CSR file (from Keychain Access)
5. Download certificate

### Step 6: App Store Connect
1. Go to https://appstoreconnect.apple.com
2. Click "My Apps"
3. Click "+" → "New App"
4. Fill:
   - Platform: iOS
   - Name: "Veltrix Sports"
   - Primary language: English
   - Bundle ID: "com.veltrix.sports"
   - SKU: "veltrix-sports"
   - User access: Full Access

### Step 7: Complete App Information
1. Go to app page
2. Fill:
   - Name (max 30 chars)
   - Subtitle (max 30 chars)
   - Description (max 4000 chars)
   - Keywords (max 100 chars)
   - Support URL
   - Marketing URL
   - Privacy Policy URL
3. Upload:
   - App icon (1024x1024 PNG)
   - Screenshots (required sizes)
     - iPhone 6.7": 1290 x 2796
     - iPhone 6.5": 1242 x 2688
     - iPhone 5.5": 1242 x 2208
     - iPad 12.9": 2048 x 2732

### Step 8: Pricing & Availability
1. Go to "Pricing and Availability"
2. Set price: Free
3. Select territories
4. Save

### Step 9: App Privacy
1. Go to "App Privacy"
2. Add privacy practices
3. Link privacy policy

### Step 10: Build Upload
1. Open project in Xcode
2. Select "Any iOS Device"
3. Product → Archive
4. Validate app
5. Upload to App Store Connect

### Step 11: TestFlight (Optional)
1. Go to "TestFlight"
2. Add internal/external testers
3. Get feedback
4. Fix issues

### Step 12: Submit for Review
1. Go to "App Store" tab
2. Click "Submit for Review"
3. Answer review questions
4. Submit

### Step 13: Review Process
1. Review takes 24-48 hours
2. Fix any issues
3. Resubmit if needed
4. App goes live
