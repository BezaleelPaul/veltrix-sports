# VELTRIX SPORTS

## Coaching, Events & Ticketing Platform

---

## Overview

Veltrix Sports is a comprehensive sports platform that connects coaches, athletes, and event organizers. The platform offers:

- **Training Plans**: B2B and B2C coaching solutions
- **Events**: Sports events management and discovery
- **Ticketing**: Marketplace for event tickets

## Quick Start

### Prerequisites

- Flutter 3.41.9+
- Dart 3.11.5+
- Android Studio / VS Code

### Setup

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/veltrix-sports.git

# Navigate to project
cd veltrix-sports

# Install dependencies
flutter pub get

# Run app
flutter run
```
